# Pattern notes

One folder per pattern. Each note follows the same shape: core idea, recognition signals, mental model, templates in Python, a worked example, the problems it covers, and the pitfalls.

Start a category by reading its note, and finish it by re-reading the pitfalls.

## Layout of a pattern folder

```
patterns/01_arrays_and_hashing/
    README.md      # the explanation
    template.py    # runnable templates with assertions
```

`template.py` is meant to be run: `python template.py` executes its assertions, so a broken template fails loudly instead of silently.
