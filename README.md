# LeetCode Practice — NeetCode 150 → 30 Patterns

A personal study log. Two phases, one after the other: finish the **NeetCode 150** to build broad pattern coverage, then work the **30-pattern reference** to consolidate what the 150 taught.

## What is in this repo

| File | What it is |
|---|---|
| [`plan.md`](plan.md) | The study plan: phase order, weekly cadence, rules |
| [`checklist.md`](checklist.md) | Every problem and pattern as a tick-box |
| [`patterns/`](patterns/) | Pattern explanations, one folder each, with Python |

## How to use it

1. Read `plan.md` once.
2. Work down `checklist.md`, one category at a time. Tick a box only when you can solve the problem unaided.
3. Read the matching `patterns/` note before starting a category, and again after finishing it.

## Progress

Update the counts as you go:

- **NeetCode 150:** 0 / 150
- **30 patterns:** 0 / 30

Tick boxes in `checklist.md` by editing `[ ]` to `[x]`.

## The two phases

**Phase 1 — NeetCode 150.** 150 problems in 18 pattern categories, ordered so each category sets up the next. Work the categories in order; inside a category, go easy → medium → hard.

**Phase 2 — 30 patterns.** A second pass that names the *transferable* pattern behind the problems: recognition signals, the invariant, the template, and where it fails. By then most problems are re-solves, not new ones.
